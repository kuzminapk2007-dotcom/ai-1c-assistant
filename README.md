# ИИ-помощник для 1С

## Запуск Python-прототипа

1. Открыть терминал в папке проекта.
2. Выполнить команду.

```powershell
python main.py
```

3. Ввести запрос, например: `Покажи продажи за октябрь по товарам`.

## Среда разработки

- Python 3.13.1
- 1С:Предприятие 8.5.1.1150, учебная версия
- Информационная база: файловая

## План интеграции

Основной способ: форма 1С обращается к локальному Python-сервису по HTTP и получает ответ в формате JSON.

COM-соединение не используется, потому что оно не поддерживается учебной версией 1С.

Запасной способ: обмен JSON-файлами между 1С и Python.

## Запуск HTTP-сервера

1. Создать виртуальное окружение:

```powershell
python -m venv .venv
```

2. Установить зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Запустить сервер:

```powershell
.\.venv\Scripts\python.exe server.py
```

4. Проверить состояние сервера:

```text
http://127.0.0.1:5000/health
```

5. Проверить разбор запроса:

```text
http://127.0.0.1:5000/parse?text=Покажи продажи за октябрь по товарам
```

Для остановки сервера нажать `Ctrl+C`.
