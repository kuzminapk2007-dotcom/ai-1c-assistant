# ИИ-помощник для 1С

## Запуск Python-прототипа

1. Открыть терминал в папке проекта.
2. Выполнить команду.

```powershell
python main.py
```

3. Ввести запрос, например: `Покажи продажи за октябрь по товарам`.

## Среда разработки

- Python 3.13.1
- 1С:Предприятие 8.5.1.1150, учебная версия
- Информационная база: файловая

## План интеграции

Основной способ: форма 1С обращается к локальному Python-сервису по HTTP и получает ответ в формате JSON.

COM-соединение не используется, потому что оно не поддерживается учебной версией 1С.

Запасной способ: обмен JSON-файлами между 1С и Python.
