# ИИ-помощник для 1С

## Запуск Python-прототипа

1. Открыть терминал в папке проекта.
2. Выполнить команду.

```powershell
python main.py
```

3. Ввести запрос, например: `Покажи продажи за октябрь по товарам`.

## Среда разработки

- Python 3.13.1
- 1С:Предприятие 8.5.1.1150, учебная версия
- Информационная база: файловая

## План интеграции

Основной способ: форма 1С обращается к локальному Python-сервису по HTTP и получает ответ в формате JSON.

COM-соединение не используется, потому что оно не поддерживается учебной версией 1С.

Запасной способ: обмен JSON-файлами между 1С и Python.

## Запуск HTTP-сервера

1. Создать виртуальное окружение:

```powershell
python -m venv .venv
```

2. Установить зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Запустить сервер:

```powershell
.\.venv\Scripts\python.exe server.py
```

4. Проверить состояние сервера:

```text
http://127.0.0.1:5000/health
```

5. Проверить разбор запроса:

```text
http://127.0.0.1:5000/parse?text=Покажи продажи за октябрь по товарам
```

Для остановки сервера нажать `Ctrl+C`.

## Сценарии MVP

1. Отчёт по продажам за выбранный период с группировкой по товарам или менеджерам.
2. Рейтинг контрагентов за выбранный период по количеству документов продаж.

## Модель данных

### Контрагент

Контрагент — покупатель, которому оформляется продажа.

Основные поля:

- код;
- наименование

Связи:

- выбирается в документе «Продажа»;
- записывается в регистр накопления после проведения документа

### Товар

Товар — позиция, которую продают покупателю

Основные поля:

- Код
- Наименование

Связи:

- выбирается в табличной части документа «Продажа»;
- записывается в регистр накопления после проведения документа;
- используется для группировки отчёта по товарам

### Менеджер

Менеджер — сотрудник, ответственный за продажу

Основные поля:

- код
- наименование

Связи:

- Менеджер выбирается в документе «Продажа»
- используется для группировки отчёта по менеджерам
- записывается в регистр «Продажи» при проведении документа

### Документ «Продажа»

Документ «Продажа» — документ, который фиксирует продажу товаров контрагенту

Реквизиты шапки:

- дата
- номер
- контрагент
- менеджер

Поля табличной части:

- товар
- количество
- цена
- сумма

Связи:

- при проведении создаёт движения в регистре накопления «Продажи»
- проведённые данные используются для формирования отчёта по продажам

### Регистр накопления «Продажи»

Регистр «Продажи» — регистр, который хранит движения проведённых документов о количестве и сумме проданных товаров

Измерения:

- контрагент
- товар
- менеджер

Ресурсы:

- количество
- сумма

### Показатели

- сумма продаж — общая стоимость проданных товаров
- количество документов — число проведённых документов «Продажа»
